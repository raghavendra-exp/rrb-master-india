## 📖 Overview

**RRB Master India** is a fast, responsive, mobile-first, and desktop-optimized Railway recruitment examination platform built specifically for Indian Railways aspirants. It operates as a 100% client-side Progressive Web App (PWA) deployable directly onto **GitHub Pages** with zero backend server dependencies.

The platform provides complete syllabus coverage, authentic CEN notification data, previous year questions (PYQs), interactive skill testing labs, and a faithful simulation of the TCS iON Computer Based Test (CBT) interface.

---

## 🎯 Primary Examinations Covered

1. **RRB NTPC (Non-Technical Popular Categories)**
   - **Graduate Posts (CEN 05/2024):** Station Master (Level 6), Goods Train Manager (Level 5), Senior Commercial cum Ticket Supervisor (Level 5), Senior Clerk cum Typist (Level 5), Junior Accounts Assistant cum Typist (Level 5).
   - **Undergraduate Posts (CEN 06/2024):** Commercial cum Ticket Clerk (Level 3), Accounts Clerk cum Typist (Level 2), Junior Clerk cum Typist (Level 2), Trains Clerk (Level 2).
2. **RRB Group D (Level-1 Posts / CEN 08/2024)**
   - 7th CPC Level 1 positions across Engineering, Mechanical, Electrical, S&T, and Traffic departments (Track Maintainer Grade IV, Assistant Pointsman, Workshop Assistants).
3. **RRB JE (Junior Engineer / CEN 03/2024)**
   - Junior Engineer (Civil, Mechanical, Electrical, Electronics, CS/IT), Depot Material Superintendent (DMS), and Chemical & Metallurgical Assistant (CMA).

## ✨ Key Features & Specialized Labs

### 1. ⚡ Authentic TCS iON CBT Test Simulator
- Exact Railway exam palette:
  - ⬜ *Not Visited*
  - 🟧 *Not Answered*
  - 🟩 *Answered*
  - 🟪 *Marked for Review*
  - 🟣 *Answered & Marked for Review (Evaluated)*
- Sectional timers, full-screen mode, question jumping, 1/3rd negative marking calculator, real-time scorecard breakdown, and post-exam review with bilingual explanations.

### 2. ⌨️ Typing Speed Lab (RRB NTPC Typing Skill Test)
- Calibrated to official RRB requirements: **30 WPM English** or **25 WPM Hindi**.
- Implements the exact Railway formula:
  - **5% Permissible Errors:** Up to 5% of total words typed are excused without deduction.
  - **10x Penalty Rule:** For each error exceeding the 5% margin, 10 words are subtracted from the gross word count.
- Includes TCS-style Strict Backspace restriction mode and real-time net/gross speed gauges.

### 3. 🧠 CBAT Psycho Lab (Computer Based Aptitude Test)
- For **Station Master** and **Traffic Assistant** candidates.
- Interactive drills for all 5 cognitive batteries:
  1. *Intelligence Battery*
  2. *Selective Attention (Odd Numbers Sum Drill)*
  3. *Spatial Scanning (Shortest Route Map)*
  4. *Information Ordering Test*
  5. *Personality Assessment*
- Automatic **T-Score Calculator** verifying whether candidate achieves the mandatory minimum **T-score of 42** in each individual battery.

### 4. 🏃 Group D Physical Efficiency Test (PET) Lab
- Digital stopwatch with live progress indicator against official qualifying benchmarks:
  - **Male Candidates:** 1000m running in 4 min 15 sec + 35 kg weight carry for 100m in 2 minutes without putting weight down.
  - **Female Candidates:** 1000m running in 5 min 40 sec + 20 kg weight carry for 100m in 2 minutes.
- Local track drill logger to record practice history and performance trends.

### 5. 🧭 Exam Discovery & Eligibility Engine
- Interactive evaluator: Input your age, category (UR, OBC-NCL, SC, ST, EWS), 10th, 12th percentage, graduation stream, engineering diploma, typing capability, and eyesight.
- Analyzes candidate profile against official IRMM medical categories (A-2, A-3, B-1, B-2, C-1, C-2) and CEN age relaxation provisions.

### 6. 🧮 Mental Arithmetic & Speed Sprint Lab
- 30-second rapid calculation sprint covering squares (11² to 40²), percentages, and multiplication tables to build speed for arithmetic questions without rough paper.

### 7. 🗂️ Spaced Repetition Flashcards (SRS)
- Active-recall digital flashcards spanning Indian Railways GK, General Science, Math formulas, and Current Affairs with "Needs Revision" and "Mastered" spaced loops.

### 8. 🗺️ All 21 RRB Zones Official Directory
- Direct access to verified official websites, regional physical headquarters, helplines, notices, and scorecard servers for all 21 Railway Recruitment Boards:
  *Ahmedabad, Ajmer, Prayagraj (Allahabad), Bangalore, Bhopal, Bhubaneswar, Bilaspur, Chandigarh, Chennai, Gorakhpur, Guwahati, Jammu-Srinagar, Kolkata, Malda, Mumbai, Muzaffarpur, Patna, Ranchi, Secunderabad, Siliguri, and Thiruvananthapuram.*

### 9. 🛡️ Strict Anti-Piracy & Copyright-Safe Directory
- 100% compliant with copyright and fair educational guidance.
- Zero unauthorized PDF hosting or pirated material.
- Connects aspirants directly to legitimate book publisher stores and free government educational portals (**NCERT**, **ePathshala**, **SWAYAM**).

## 🚀 Getting Started

### Prerequisites

Ensure you have Node.js (version 18 or above) installed on your machine:

```bash
node -v
npm -v
```

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/raghavendra-exp/rrb-master-india.git
cd rrb-master-india
npm install
```

### Local Development

Launch the Vite local development server:

```bash
npm run dev
```

Open your browser and navigate to `http://localhost:5173`.

### Production Build

Verify TypeScript types and build optimized static assets:

```bash
npm run build
```

The compiled output will be generated inside the `dist/` directory.

### Preview Production Build

```bash
npm run preview
```

## 🌐 Deploying to GitHub Pages

This repository includes a ready-to-use GitHub Actions workflow configured in `.github/workflows/deploy.yml`.

To deploy:
1. Push your code to the `main` branch:
   ```bash
   git push origin main
   ```
2. In your GitHub repository:
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment** > **Source**, choose **GitHub Actions**.
3. The workflow will automatically build the project and publish it live!
